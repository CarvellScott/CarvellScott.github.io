### Grocery Scanner

- **Project Title:** Grocery Scanner
- **Description:** I got tired of "taking attendence" with my groceries when it came to figuring out what I needed to pick up, so I made a web app that would allow me to scan NFC tags/QR codes affixed to the containers which would let me add them to my grocery list just by scanning them. My grocery store doesn't want to make their API public (presumably to counteract price monitoring), so I settled for directing a logged-in user to the item page. The NFC tags are designed to link to an autogenerated static web page which uses javascript to redirect the user to an item listing based on URL parameters. The project uses only the python standard library and bottle.py with a Makefile-based workflow.

### Cooking for Coders

- **Project Title:** Cooking for Coders
- **Description:** A publishing workflow built around Markdown and Pandoc for producing multiple versions of my Mom's recipe book, "The Oven of Eden". Formats include an interactive single-page webapp, a printed copy, a progressive web app I installed on her phone, and finally an Amazon Kindle-compatible e-book format. She wants to keep her recipes secret, so this repo is going to contain a version with random recipes I like instead.

### PYTHON INTENSIFIES

- **Project Title:** PYTHON INTENSIFIES
- **Description:** Back when I was working at Rackspace, we were allowed to upload custom emojis to Slack. The `[___ intensifies]` meme was one of my favorites, so I built a tool to take a pic and make a GIF of it being shaken vigorously. It's fairly outdated because nowadays the only place I'm allowed to upload absurd numbers of custom emojis is Discord. At the time the project uses Python and the PIL image manipulation library. If I were to redo/revisit this, I'd likely add support for different formats, likely encoding the output into an SVG, and adding text overlays.
